# Comprehensive Algorithm Laboratory

Structured progression of practical algorithmic exercises, data transformation modules, and procedural problem-solving routines.

*Leia isto em [Português](README.pt-BR.md).*

---

## Structure

The laboratory contains discrete activity modules organized progressively:
- `Atividade_A` to `Atividade_U`: Discrete assignments addressing input/output formatting, mathematical formulas, conditional branching, iteration loops, array sorting/filtering, and matrix traversal.

---

## Execution

```bash
npm install
node Atividade_A/<script>.js
```
