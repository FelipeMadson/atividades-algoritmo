# Laboratório de Exercícios e Práticas de Algoritmos

Conjunto progressivo de atividades práticas, manipulação de estruturas de dados e resolução de problemas algorítmicos em JavaScript.

*Read this in [English](README.md).*

---

## Estrutura do Laboratório

O repositório é organizado em pastas modulares por nível de complexidade:
- `Atividade_A` a `Atividade_U`: Resoluções de problemas de entrada/saída, operadores aritméticos, estruturas de decisão (`if/else`), repetições (`for`, `while`), vetores e matrizes.

---

## Execução

```bash
npm install
node Atividade_A/<script>.js
```
